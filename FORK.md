# FORK.md

Insiro's fork of ELYTerminal (upstream `ELY-Open-Source/ELYTerminal`). It keeps the experience of Orca, an agent workspace app, without its weight: projects and their git worktrees in the sidebar, tabs per workspace, document previews, agent usage, simple git. Where this file and `AGENTS.md` differ, this file wins. `AGENTS.md`, `PRD.md` and `TASKS.md` stay as upstream writes them, so syncs merge cleanly.

## Goals, in order

1. Workspaces: projects and their worktrees in the left column, a tab strip per workspace, `workspace.json`, Claude sessions resumed by id.
2. File preview in the right column, a document tab in the main area: Markdown, JSON, YAML, XML, images, text; HTML through Ely's `WebView` on macOS, its source elsewhere.
3. Agent usage: Claude's rate limits from its OAuth usage API and a statusLine wrapper the user turns on, Codex's from `codex app-server`, ChatGPT's page and its session files.
4. Git: push, pull, fetch, undo commit, checkout, new branch, merge and abort, history paging.

Out of scope: an editor, creating worktrees, skills, automations, plugins, chat UI, remote control, cloud sync.

## Layout changes

- `src/projects.rs`: `Home` (a workspace: Others, or a project's folder or worktree), `TabId`, `normal` and `home_of`. `projects/store` reads and writes `workspace.json` beside `settings.json`, a corrupt file moved aside as `workspace.json.broken-SECS`; `projects/claude` makes v4 session ids and finds their transcripts; its `Modes` searches restored ids' transcripts off the main thread, and `Watch` follows a Claude tab's marks to Claude's command's end.
- `src/atomic.rs`: the temp-file-and-rename save that settings and `workspace.json` share.
- `src/git/worktree.rs`: `git worktree list --porcelain`, `-z` from git 2.36 and lines before it; a repository's subfolder counts as a plain folder. `src/git/discard.rs`: a change discarded alone, or a folder's at once, one call a kind.
- `src/workspace/tabs.rs`: tabs, each in a home, the shown one per home. `workspace/strip.rs`: the tab strip over the terminal, `+`, profiles and the ⋯ menu; `strip/row.rs` its row of tabs in Ely's `EditorTabs` look, a tab dragged to a new place. `workspace/dialogs.rs`: the questions over the window: rename a tab or a project, remove a project, close a tab Claude runs in, and notices. `workspace/sidebar.rs`: the left column's rows; `sidebar/menu.rs` what a right press on a project's or a worktree's row offers; `sidebar/drag.rs` a project's row dragged to a new place.
- `src/workspace/projects.rs`: the projects the left column lists, added, renamed, expanded, reordered and removed, their tabs with them. `workspace/refresh.rs`: each project's worktrees listed off the main thread, one listing a project at a time, a late one dropped; a window's activation lists again at most every 2 s.
- `src/workspace/persist.rs`: `workspace.json` kept, a snapshot saved 0.5 s after a change and flushed at close, restored at start, each home's tabs woken as it is selected, a tab that fails to start kept; `persist/shape.rs` maps projects and tabs to the saved state and back.
- `src/workspace/claude.rs`: Claude tabs: a shell handed `ELY_CLAUDE` and the prelude, its marks watched, 20 s from the first prompt for Claude to start, a close confirmed while Claude runs, its id copied.
- `src/settings`: `claude_prelude`, a command a Claude tab's shell runs before `claude`. `src/term/marks.rs`: `Mark::Unstarted`, the integration's bare `D;aid=elyterminal`; the view emits `TerminalEvent::Marked` while a Claude tab watches.
- `assets/shell-integration`: zsh, bash, fish and pwsh run `ELY_CLAUDE`'s `claude` once, at the first prompt, then unset it.
- `src/docs.rs`: `Document`, one file shown in the right column's preview or a tab, `Place::Panel` or `Place::Tab`; it looks at the file's stamp each second off the main thread while visible and reads only a change. `docs/kind.rs` judges Markdown, JSON, YAML, XML, image, HTML or text by extension, with the limits (2 MiB, images 50 MiB) and icons; `docs/read.rs` reads without blocking, bounded, and tells binary, too large or failed; `docs/links.rs` resolves a Markdown link; `docs/view.rs` draws each kind through Ely's `MarkdownRenderer`, `JsonViewer`, `YamlViewer`, `XmlViewer`, `ImageViewer` and a read-only `CodeEditor`; `docs/web.rs`, macOS, an HTML file's stamped `file://` address.
- `src/files/listing.rs`: Files' folder entries, keys and Git badges, moved out of `files.rs`; Files emits `Preview` and `OpenTab`, and its menu offers both on a file.
- `src/workspace/preview.rs`: the preview under Files' tree in Ely's `SplitPane`, its header and its share. `workspace/doctabs.rs`: document tabs opened once per home, and their ⋯ menu. `workspace/tabs/body.rs`: `Body::{Term, Doc}` and what a tab does by its body. `workspace/persist/wake.rs`: a home's saved tabs started, documents among them.
- Tests: `src/docs/tests.rs`, kinds, reads, links and page addresses; `workspace/doctabs/tests.rs`, one tab per path and home; `src/term/shell/tests/claude.rs`, each shell runs `claude` once; `src/git/tests/worktrees.rs`, worktree listing; `src/projects/tests.rs`, `workspace/tabs/tests.rs`, `workspace/projects/tests.rs` and `workspace/persist/tests.rs`.
- `src/usage.rs`: `Usage`, one app-wide entity of the latest Claude and Codex readings and the wrapper's status, polled every 2 s off the main thread while a `Watch` lives, a minute's redraw for countdowns; `usage/claude` reads `rate_limits` from a statusLine input; `usage/codex` finds the newest rollout of the newest 3 day folders by mtime and reads its `token_count` lines through `ruzstd`, nothing else parsed; `usage/poll` reads a file only when its stamp changed and sweeps temps the wrapper left; `usage/install` plans, applies, reverts and forgets the statusLine wrapper; `usage/time` ages, resets and UTC times; `usage/view` the Usage tab; `usage/summary` the projects column's last line. `assets/usage/claude-statusline.sh` is the wrapper. `src/settings/window/usage.rs`: Settings › Usage and its consent dialog. `src/workspace/usage.rs`: a window's watches. `atomic::write_if` lets a caller stop the rename. Tests: `src/usage/tests.rs`, `tests/install.rs`, `tests/view.rs`.
- `src/usage/live.rs`: `Origin`, `Fetched`, `Trouble`, `Live` and `Schedule`, a fetch at a watch's start and every 10 minutes, a 429 holding it; `usage/run` runs `curl` and `security` bounded by time, headers on curl's stdin, `Secret` hiding a token's Debug; `usage/keychain` reads Claude Code's Keychain item, suffixed by `CLAUDE_CONFIG_DIR`'s hash, else `.credentials.json`; `usage/api` asks `api/oauth/usage`; `usage/appserver` asks `codex app-server` over JSON-RPC, finding `codex` on `PATH`, in the usual folders or by the login shell; `usage/web` asks ChatGPT's `wham/usage`. `Usage::claude_shown` and `codex_shown` show each source's newest reading and where it came from. Tests: `src/usage/tests/live.rs`, a fake app server among them.
- `src/git/graph.rs`: the commit list's lanes, from each commit's parents through Ely's `lanes`. `src/git/panel/tree.rs`: a section's changes as folder and file rows, a chain of lone folders on one row; `panel/grouped.rs` draws them in the look of Ely's `ChangesList`, with each folder's stage, unstage and discard. `git_tree` in the settings keeps the choice. Tests: `src/git/panel/tree/tests.rs`, and the lanes' in `graph.rs`.
- `src/workspace/panels.rs`: each home's right column, its tab, preview and share, kept as the window leaves the home, shown on its return, and saved in `workspace.json`'s `panels`. `src/files/kept.rs`: Files' open folders and chosen node by root, kept as the tree leaves a root.
- `src/workspace/worktrees.rs`: a linked worktree removed through `git worktree remove`, asked first with its path, branch, open tabs and whether `git status --porcelain` finds changes; `git::worktree_dirty` and `git::remove_worktree` in `git/worktree.rs`. `src/i18n/en_workspace.rs` and `zh_workspace.rs`: the fork's later words, joined after each catalog, so `en.rs` stays under 500 lines.
- `src/workspace/parked.rs`: tabs saved for later, `store::Parked` in `workspace.json`'s `parked`, saved, resumed and deleted; `parked/view.rs` their rows under each home's row, their menu and dialogs. `src/term/screen.rs`: a terminal's screen and last 200 history lines as text, and whether its shell runs a command. Tests: `workspace/parked/tests.rs`, and the text's in `screen.rs`.
- `src/identity.rs`: the fork's name, `ELYTerminal Insiro`, its app id `com.insiro.elyterminal`, and its config and data folders, which settings, `workspace.json`, usage and the shell integration take; `identity/migrate` copies upstream's `settings.json` and `workspace.json` once and strips the fork's keys from upstream's settings. Tests: `src/identity/tests.rs`. `packaging/linux/com.insiro.elyterminal.desktop` replaces upstream's entry.
- Gone: `workspace/rename.rs`, `workspace/reorder.rs`, `sessions::row`; the sessions column is the projects column.

## Decisions

- 2026-11-04: the left column lists projects and their worktrees, not sessions; a tab strip over the terminal shows the selected workspace's tabs. A press on a project's row opens its main worktree; worktrees are listed and, since 2026-11-06, removed, never created.
- 2026-11-04: closing the last tab keeps the window; only its close button or Quit closes it.
- 2026-11-04: a tab shows its state by its icon's shape (hourglass, X, loader, check, bell), since Ely's `EditorTabs` colors every icon as its title; the colored marks live on the left column's rows. Rename, duplicate and close sit in the ⋯ menu beside the strip; no Ely fork.
- 2026-11-04: settings keep `drag_sessions`, `session_menu` and `sessions_width`, now meaning tabs and the projects column, so settings files from upstream still load.
- 2026-11-04: a Claude tab is started by the shell integration at its first prompt, from `ELY_CLAUDE=new:ID` or `resume:ID`, after an optional user command such as `nvm use default`.
- 2026-11-04: Windows is checked later, in one pass.
- 2026-11-04: a Claude tab runs `claude` as a command line of its own at the first prompt: zsh types it through `zle-line-init`, PowerShell's read hands it over, fish runs it at a private key (U+E000) the app sends once the first prompt reads, since fish aborts if a line runs while its own question to the terminal is open, and bash runs it from the last prompt command. A prompt start leads straight into it, which tells it from a line typed ahead; keys typed before the first prompt reach `claude` itself where it starts at once (zsh, PowerShell). Its end clears the id, as does the integration's `D;aid=elyterminal`, which says it does not start, or 20 s from the first prompt without it; a suspend (128 + SIGTSTP) does not. A restored tab resumes unless the transcript search, given 300 ms, finds none; a WSL tab always resumes. cmd runs it through `/k`, marks no command, and keeps its id until the tab closes; its prelude may hold no `"` or `%`.
- 2026-11-04: a file chosen in Files previews under the tree, split 0.45 to the tree at first and kept while the window lives; Open as Tab, a link to a file or a restored tab opens it as a tab of the selected home, the tab already showing that path there if one does. A document tab closes without asking, has no rename or duplicate, and leaves Files and Git on the folder they showed. Its path must be UTF-8, since `workspace.json` keeps text; it saves as `{"kind": "doc", "path": ...}` and restores though its file is gone, under a banner, its file read only once shown.
- 2026-11-04: a document reads its file only while visible, once a second by its stamp, and draws again only when it changed; a file gone keeps its last read under a banner and comes back with it. Text over 2 MiB, images over 50 MiB, a NUL in the first 8 KiB or bytes not in UTF-8 show a notice and the system's app. An image's picture leaves the cache and the window's atlas when it changes and when its document goes; a picture Ely's viewer turned is its own and stays.
- 2026-11-04: on macOS an HTML tab shows its page in Ely's `WebView`, a `file://` address stamped with the file's time and size, so a change reloads; a page draws over all gpui paints, dialogs and menus too, so it shows only while no dialog asks and the document holds the keys, else its source, and comes back reloaded, its scroll lost. The preview and other systems show the source and Open in Browser. Whether WebKit loads the styles and pictures beside a page loaded by `loadRequest` went unchecked: the shot's window drew no frame while the screen was locked.
- 2026-11-04: Markdown, JSON, YAML and XML documents select no text, which Ely's views do not offer, and the Edit menu's Copy and Select All are `forms` actions, which the read-only `CodeEditor` does not take; its own Cmd-C binding copies inside it.
- 2026-11-05: a project moves by a drag of its own row, not Ely's `Reorder`, which drops only inside its box and lands by the held block's middle, so a tall project jumped and a release off the rows moved nothing. The place follows the pointer's height, before the first block whose middle lies below it, marked by an accent line; a release anywhere in the window takes it, Escape cancels. The tab strip does the same across: its row, drawn in `EditorTabs`' look since that drops only on a tab and keeps its drag private, places a tab before the first whose middle lies right of the pointer, the line on that tab's left edge or the last one's right, and takes a release in the gap, past the last tab or over the terminal; a press selects, a middle press and × close.
- 2026-11-05: Claude's 5-hour and weekly limits come from the statusLine input Claude Code hands its command, never its API, OAuth token or Keychain. Settings › Usage › Turn on… shows the statusLine before and after and writes `settings.json` only on Apply: a backup `settings.json.elyterminal-SECS.bak` beside it, the file written again with 2-space indents and its keys in order, refused when its statusLine changed since the dialog opened or the file changed before the rename. Turn off puts the original value back; a line someone else changed meanwhile shows Changed elsewhere and is never written, Forget dropping only the app's files. Show manual steps writes only the app's files and shows the line to paste. The wrapper, in the app's `usage` folder (0700), keeps the whole input that holds `rate_limits` (0600, temp and `mv`), then `exec`s the original command through `/bin/sh -c` with the same input, so its output, status and cancellation pass through. A project's own statusLine passes the wrapper by. Windows' PowerShell wrapper waits for the Windows pass.
- 2026-11-05: Codex's limits and tokens come from its newest session file, read only, on by default (`codex_usage`); compressed past 64 MiB, unpacked past 256 MiB is an error, a line past 4 MiB skipped, a plain file's last 1 MiB read, a truncated frame ends the read with the lines before it. Files are read only while a Usage tab or summary shows; a reset passed shows "waiting for new data", never a guessed percent; meters turn warning at 80% and danger at 95%. The projects column's last line (`usage_summary`, on) shows each source's 5-hour and weekly percents, a source without data left out; its press shows the Usage tab.
- 2026-11-05: a document's `CodeEditor` stays read-only: Ely's read-only banner always offers Make editable, and its press unlocks the editor and emits `EditorEvent::Unlock`, so the document locks it again at that event, logged, and the press changes nothing; Ely `294a832` has no way to hide the button. With the notice of a corrupt `workspace.json` up, Quit does nothing until it is dismissed: gpui's prompt is an AppKit sheet, and AppKit terminates no app with one attached, so `shot` ends any sheet before it quits.
- 2026-11-06: the user chose Orca's way for usage, lifting 2026-11-05's rule against Claude's API and token: while a Usage tab, the summary or Settings › Usage shows, Claude's limits come every 10 minutes from `api.anthropic.com/api/oauth/usage` with Orca's headers and Claude Code's own token, read from the Keychain (`security`, 3 s) or `.credentials.json`, never refreshed or written; an expired or refused token says open Claude, and the statusLine stays a source. Codex's come from `codex -s read-only -a never app-server` (initialize, initialized, `account/rateLimits/read`, 10 s each, its process group killed), else from `chatgpt.com/backend-api/wham/usage` with `auth.json`'s token; the session file still gives tokens and a last fallback. Each source shows its newest reading by time, and from where. A 429 holds the fetch for its `Retry-After`, at least 10 minutes, else 15. A token goes to curl only on stdin, never in argv or the log. `claude_api_usage` and `codex_live_usage`, on by default, turn each off.
- 2026-11-06: after a security review: curl runs from its own path (`/usr/bin/curl`, Windows' `System32\curl.exe`) with `-q`, so no `.curlrc` traces or proxies the token, and `--proto =https`; a header with any control character is refused; curl's complaint shows its last line, none naming Authorization; output past 4 MiB is drained and refused as too large; the login shell's lookup runs in its own process group, killed whole; the app server's lines are capped at 1 MiB; a Keychain refusal or timeout falls through to `.credentials.json` and the Keychain is not asked again for an hour; ChatGPT's 429 holds the fetch as Claude's does; each fetch runs on a thread of its own, off gpui's pool. The live cadence is 10 minutes, at the user's word.
- 2026-11-06: the Git panel lists changes flat in Ely's `ChangesList`, or by folder, VS Code's way, as the header's button switches and `git_tree` keeps, off by default. Ely's list has no grouping, so the tree is the fork's own rows in its look: folders first, each by name ignoring case, a folder holding one folder alone on one row (`src/term`), each folder open until pressed, with its count; a folder's stage, unstage and discard act on every change under it in its section, the full list though only 500 are drawn, and its discard asks first, then runs one `git` call a kind, `restore` for edits, `rm` for files only intended to be added or renamed, `clean` for untracked ones, each kind run even when another fails and the failure naming how many of how many went and which kind; its question says how many new files are deleted when the folder holds any. The commit list draws lanes beside its rows as `git log --graph` does, through Ely's `CommitList::graph` and `lanes`, the log read in topological order so each commit comes before its parents; a parent past the 50 commits leaves its lane open at the bottom.
- 2026-11-06: the right column keeps its state per home, which the owner asked for when a switch of project lost the folders opened and the preview. Files keeps each root's open folders and chosen node as it leaves the root, by root, not by home, so a `cd` inside a tab and back opens that root's own tree, never another's; a tree with only its root open and nothing chosen is not kept. The workspace keeps each home's tab (Git, Files or Usage), preview and split share as the window leaves the home and shows them on its return; a home never left keeps what shows. The tab shown is the window's own, kept per home in `workspace.json` alone; `panel` in the settings is the tab of a home with none kept, written only when the user presses a tab, so a home switch writes no `settings.json`; a change of `panel` from elsewhere, the usage line among them, shows in the window. A folder opened or closed in the tree, a tab turned, and a preview opened or closed save `workspace.json` 0.5 s later, as any change does. A switch to a home whose shown tab is a document now shows that home's folder in Files and Git. `workspace.json` gains `panels`, each home's tab, preview path and the folders open in the tree of the home's own folder, its worktree or, for Others, the home folder; absent in older files; a path not UTF-8 is left out. - 2026-11-06: a right press on a linked worktree's row offers Remove worktree…, which the owner asked for; the main worktree, the first git lists, and a home git does not list offer none. Its dialog names the path, the branch, the tabs that close and the Claude tabs among them, and, when `git status --porcelain -z --untracked-files=normal --ignored`, run off the main thread, finds a change, that it will be lost, its button then Remove anyway, which passes `--force`; it names the ignored entries git finds, up to three and how many, `.env` and build output among them, which `git worktree remove` deletes force or not.
